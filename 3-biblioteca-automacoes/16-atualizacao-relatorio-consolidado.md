### 11. Relatório Consolidado

**O que automatiza:** junta dados de fontes diferentes num relatório único, pronto para leitura da liderança.

**Pré-requisitos:** os arquivos/fontes de dados (planilha de horas, export do sistema de projeto, e-mails de status) na pasta ou conectados.

**Prompt:**
```
Consolide os dados desta pasta — a planilha de horas, o export do sistema de 
projeto, e os e-mails de status recebidos esta semana — num relatório único 
para a liderança. Estruture como: resumo executivo (3-4 linhas), principais 
avanços, riscos identificados, e o que precisa de decisão da liderança.

Onde os dados de fontes diferentes divergirem (ex.: horas reportadas vs. horas 
no sistema), sinalize a divergência em vez de escolher um número silenciosamente.

Salve como Relatorio_[período]_[projeto].docx nesta pasta.
```

**O que esperar de saída:** relatório pronto para envio, com divergências entre fontes explicitadas, não escondidas.
