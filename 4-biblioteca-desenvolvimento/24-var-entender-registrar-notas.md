### 24. Registrar notas do que foi descoberto
**Etapa:** Variação · Entender o código
**Ferramenta:** Claude Code

**Quando usar:** Depois de uma sessão de exploração, para não perder o que foi aprendido sobre o código.

**Prompt:**

```
Com base no que exploramos nesta sessão sobre [nome do módulo ou objeto], registre um resumo em um arquivo de notas (sugira o nome e a pasta, por exemplo notes/ZMM_NOTIF_GR_FI.md), cobrindo:

1. O que o objeto faz e por quê.
2. As dependências mais importantes.
3. Qualquer ponto confuso ou mal documentado que valeria uma pergunta para o time.

Não precisa ser formal, é para consulta rápida futura.
```

**O que esperar de saída:** Um arquivo de notas criado com o resumo do que foi explorado, incluindo pontos confusos a esclarecer com o time.

**O que conferir:** Se o arquivo foi criado na pasta sugerida e se as notas realmente ajudariam você, ou outra pessoa, a retomar o assunto sem reexplorar tudo de novo.
